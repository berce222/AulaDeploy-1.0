Desarrollo y despliegue web

Desarrollo web

El desarrollo web consiste en crear y mantener sitios y aplicaciones que funcionan en un navegador. Para ello se utilizan tecnologías como HTML y CSS, que permiten estructurar y presentar el contenido.

Despliegue

El despliegue consiste en preparar una aplicación para que pueda ejecutarse en un servidor y estar disponible para sus usuarios. Un proceso organizado permite publicar cambios de forma controlada y segura.

Colaboración

El trabajo colaborativo permite que varias personas participen en un mismo proyecto utilizando herramientas como Git y GitHub. Las ramas, los commits y las pull requests ayudan a organizar y revisar los cambios.
